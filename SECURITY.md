# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, open a private security advisory:
[https://github.com/Bl4nk44/plane-ce-mcp/security/advisories/new](https://github.com/Bl4nk44/plane-ce-mcp/security/advisories/new)

Include as much of the following as you can:

- Type of issue (e.g. credential leak, auth bypass, injection)
- Affected file(s) and version/commit
- Steps to reproduce or proof of concept
- Impact assessment

You should receive a response within a few days. Please allow time for a fix to be
released before public disclosure.

## Scope

This policy covers the plane-ce-mcp codebase only. Vulnerabilities in Plane itself
should be reported to [Plane's security policy](https://github.com/makeplane/plane/security/policy).

## Supported versions

Only the latest release / `main` branch is supported with security fixes.
